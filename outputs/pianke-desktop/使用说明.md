# 片刻 Mac 宿主 · 0.3.5 / build 12

AppKit + WKWebView，面向Apple芯片、macOS14及以上。在仓库根目录执行 `zsh outputs/pianke-desktop/build.command`，生成 `outputs/片刻.app`；可传入独立输出路径。需要Xcode Command Line Tools，仅做本地签名，未做发行公证。

点击菜单栏水波图标或按⌘⇧K呼出、收起。当前没有开机自启。固定录音全部随包保存，练习时无需网络和API Key。默认不写诊断日志；显式传入 `-diagnostics` 和目标文件路径时，日志可能包含应用路径和窗口状态，分享前应清理。

完整使用、隐私、已知范围与许可见根目录README、PRIVACY.md、NOTICE.md。不要同时运行同标识的多个副本。
