# 片刻 Mac 宿主

0.3.1 / build 8，AppKit + WKWebView，面向 Apple 芯片、macOS 14 及以上。

在仓库根目录运行 `zsh outputs/pianke-desktop/build.command`，默认生成 `outputs/片刻.app`。构建脚本也可接收自选应用包路径。构建需要 Xcode Command Line Tools，只进行本地签名，没有发行公证。

点击菜单栏水波图标或按 ⌘⇧K 呼出 / 收起；原生沉浸窗口覆盖当前屏幕，不创建新 Space。当前没有开机自启。不要同时运行同标识的多个副本。

默认不写诊断日志；如显式传入 -diagnostics 和目标文件路径，日志可能包含应用路径与窗口几何信息。分享日志前请清理。声音、练习记录、当前限制与素材许可见根目录 README、PRIVACY.md 和 NOTICE.md。
