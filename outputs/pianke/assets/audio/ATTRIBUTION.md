# 片刻音频来源与许可

本次使用用户已选音轨。环境音来自 Freesound 官方 HQ MP3（未下载登录后原 WAV）；音乐来自作者公开 MP3。转码不会提升原始录音清晰度。

工程处理：双遍 EBU R128 响度归一，既有六轨保持原成品；新增 A05–A07 / M03–M04 目标 -25 LUFS / -3 dBTP；受峰值和响度范围约束时使用动态处理（见 manifest 实测值）。首尾各 20 ms 淡化，AAC 160 kbps / 44.1 kHz / 立体声。没有合成或混入其他声音。播放器需按 manifest 做交叉淡化循环；A03 原素材仅约 9.5 秒，重复感仍待试听验收。

文件全程解码、响度与真峰值检查通过，不代表已通过主观试听或用户验收。
