# 片刻第二轮 · 眼部动作模块的来源与边界

记录日期：2026-10-17；时序修订：2026-10-18，Asia/Shanghai。模块：`eye-guide.js`、`eye-guide.css`。

## 本次选定内容

采用福建省教育厅 2020 年发布、委托福建省儿童青少年近视防控研究中心（福建医科大学医学技术与工程学院眼视光学系）老师讲解的**六节眼保健操顺序与动作事实**。不再使用此前待核验的“北京 2008 五节”标识，二者不混用。

- 主来源：[福建省教育厅《眼保健操，你真的做对了吗？｜2020爱眼日》](https://jyt.fujian.gov.cn/jyyw/jyt/202006/t20200608_5295124.htm)，发布于 2020-06-08，本次已读取完整正文。该页附有完整教学视频；视频不是本产品的复制素材，未在此声称逐帧观看或获得传播授权。
- 卫生及不压眼球的补充来源：[成都中医大银海眼科医院《国家卫健委推广耳穴压丸等中医适宜技术防控近视》中的“做眼保健操注意事项”](https://ineyehospital.com/m/news/ineye/364.html)，发布于 2023-07-31，本次已读取正文。不引入文章中耳穴压丸治疗内容。
- 穴位与手法交叉参考：[北京市卫健委转载中国中医科学院眼科医院《眼保健操里的穴位秘密》](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jksh/202501/t20250127_4001149.html)，2025-01-22。该文风池采用食指和中指；本产品统一按主来源使用拇指抱头示意，不将不同手法拼接成同一套。

## 六节逐项对应

| 顺序 | 动作与定位依据 | 原创示意方式 |
| --- | --- | --- |
| 1 | 攒竹：两侧眉头凹陷，拇指指腹按揉，其他指尖抵额 | 正脸、眉头双侧定位、拇指与额上手指的简化轮廓、小范围环形位移 |
| 2 | 睛明：鼻骨两侧近内眼角，食指上下轻按 | 点落在鼻侧内眼角之外，食指上下小幅位移；明确“不压眼球” |
| 3 | 四白：食中指并拢，中指第一关节对齐鼻翼后收回中指；眼眶下方食指轻揉 | 正脸、瞳孔下方眶缘以下的定位；文字写明定位过程，不把点放在下眼睑 |
| 4 | 太阳：眉梢外后方凹陷，拇指揉前四拍；后四拍食指第二指节内侧沿眉骨向外轻刮，两拍一次、共两次，重复四轮 | 太阳双点；揉/刮阶段由同一时间轴切换；独立上眉骨轨迹和指节动画，不画下眼眶刮动 |
| 5 | 风池：后枕骨下两侧凹陷；双手抱头，用拇指轻揉 | 明确“后侧”视图、枕骨及颈部两筋参照、两侧拇指；不画喉部或颈前按压 |
| 6 | 耳垂及脚趾：拇指食指轻捏耳垂正中，同时脚趾随拍轻抓、放松 | 耳垂双点、双指简化轮廓、脚趾小示意与同步轻动 |

原始网页的预防/治疗效果用语未移植到产品。主来源服务儿童青少年，不能据此声称本模块经过成人临床验证。动作示意由代码原创绘制，未经过眼科/康复专业人员逐图审校。定位图是示意比例，不能代替面诊或专业取穴教学；产品文案采用定位参照，不宣称像素级人体通用坐标。

## 时序与口令

这是为桌面跟练设计的原创教学时间轴，**不是原视频原始配乐节奏或原始总时长的复刻**：

- 开场仅播报“眼保健操。跟随示意，轻柔完成六节动作。”；卫生提示保留在设置及开场文字里。
- 每节先自然讲完简短手法，随后显示 **2、1**，倒数结束立即开始四个八拍。没有固定的准备空等，也不在开拍时插入额外讲解。
- 每拍 1 秒（60 BPM），每节 32 秒。总时长由实际语音长度决定，不再声称固定 5 分 06 秒。
- 静音、关闭人声、没有可用中文声音或语音失败时，保留该节完整文字与示意，直接倒数 2 秒再练习；静音开场文字显示 2 秒。正常连续静音的理论时间为 206 秒，产品不以此冒充有声总时长。
- 第四节每个八拍：1—4 拇指揉太阳穴；5—6 沿眉骨从内向外刮一次；7—8 再刮一次。重复四组。
- 呼吸提示使用“自然呼吸”，不要求用户刻意深呼吸。
- 所有倒数、节拍和动画由主会话传入的同一活动 `elapsed` 驱动；讲解完成由实际语音事件报告。暂停冻结倒数与节拍；讲解中暂停后，恢复会重新播放当前短句。静音恢复走文字倒数。
- 取消前先使语音令牌失效，结束、换会话和旧回调不能误推进。语音未开始 3 秒、已开始却始终没有结束事件时采用活动时间的故障回退；后者为 `min(40, max(12, 字符数 × 0.6 + 5))` 秒。这是异常防卡住的产品保护，并非正常讲解的固定等待或经临床验证的参数。
- 动画光点仅小范围位移；减少动态效果时保留明确的动作文字与静态定位，不靠闪烁提示。

## 组合休息的独立方向性眼动

提供 `restTimeline` / `restStateAt()` 数据，不与六节按摩混合，也不称为“第七节”。

依据：[国家卫健委 WS/T 773—2020《传染病疫情居家隔离期间儿童青少年近视防控指南》](https://www.nhc.gov.cn/fzs/c100048/202008/d42388863f2340c4a3ca880b3e6b2c50/files/1733125825170_45982.pdf) 第 4.2.2 节提到短暂闭眼/睁眼以及上下左右眼球运动；范围是特定儿童青少年居家情境，不是成人治疗方案。

模块采用自然眨眼 12 秒，然后正前方、上、正前方、下、正前方、左、正前方、右、正前方各 4 秒，之后闭眼休息。**4 秒与先后顺序是产品交互取舍，未声称是研究验证剂量。** 不做快速或极限绕圈，不要求一直凝视屏幕；只在舒服小范围内移动，不适随时闭眼/结束。需要成人适用性和参数的后续专业审校。

## 接入 API

先引入 `eye-guide.css` 和 `eye-guide.js`，脚本不依赖其他第三方库。

```js
// 创建一条会话状态机。totalDuration 为 null，不能作为完成条件。
const pacer = PiankeEyeGuide.createPacer();
PiankeEyeGuide.mount(document.querySelector('#experience'), {
  state: pacer.snapshot(), paused: session.paused, reducedMotion: reduceQuery.matches
});
// 每帧使用主会话同一个活动 elapsed，且只在声音可实际播放时启用人声。
pacer.tick(session.elapsed, {voiceEnabled: canPlayVoice});
for (const effect of pacer.drainEffects()) {
  // speak：主音频引擎播放 effect.text，保存 effect.token。
  // onstart -> pacer.speechStarted(token, currentElapsed)
  // onend -> pacer.speechFinished(token, 'end', currentElapsed)
  // onerror -> pacer.speechFinished(token, 'error', currentElapsed)
  // cancel：主音频引擎取消该 token；不能等待 cancel 的回调。
}
const state = PiankeEyeGuide.update({
  state: pacer.snapshot(), paused: session.paused, reducedMotion: reduceQuery.matches
});
// phase: opening / explanation / countdown / practice / done。
// countdown: 2 或 1；practicing / beat (1–8) / set (1–4) / beatIndex (0–31)
// 驱动节拍音。state.done 才是完成条件；state.step.number 为 1–6。
// 暂停/恢复先调用 pacer.setPaused(value, currentElapsed)。
// 主动静音/取消讲解调用 pacer.interrupt(reason, currentElapsed)。
// 回调先检查仍为当前会话及 pacer.isCurrentSpeech(token)。
pacer.dispose(); // 结束/换会话：先使旧回调失效，再执行取消效果。
PiankeEyeGuide.destroy();
```

`snapshot()` 返回当前状态；`stateAt(snapshot)` 是绘制时的状态规范化，不再根据一个秒数猜测语音是否完成。`timeline` 保留开场、六节和结束的内容顺序，没有固定 start/end。`render(options)` 返回初始 HTML；`mount/update/destroy` 管理一个活动绘图实例，同一节内不重建 SVG。模块**不调用语音、AudioContext、计时器或 requestAnimationFrame**。主会话统一处理播放/暂停/窗口隐藏，避免声音和画面各走一套节奏。练习阶段只使用轻拍音，不在 32 秒节拍起点重复朗读讲解。当前继续使用本机原有人声；已选 V01 的专用引导音轨仍延期，未声称已经替换。
