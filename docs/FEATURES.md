# 片刻可以做什么

片刻面向电脑阅读、学习和工作之间的短暂间隙。它把休息方式放在三个入口中，用户选择一种，停留几分钟，再回到手边的事。当前版本为 0.3.6 / build 13。

## 放松一下

| 功能 | 实际行为 |
| --- | --- |
| 呼吸引导 | 3 / 5 / 10 分钟；鼻吸 4 秒、口呼 6 秒。前两轮固定人声引导，此后使用提示音。水波或烟圈与吸呼时间同步，可关闭人声或声音 |
| 身体扫描 | 5 / 10 分钟；从鼻尖、眼睛等五官向下引导十八个部位。无面容、无性别的发光打坐轮廓对应位置微亮，可以闭眼听声音 |
| 自然声景 | 3 / 5 / 10 分钟；七种实录声音，每种两张 AI 静态画面。选择按类别保存，会话中换图不重启声音或计时 |
| 引导想象 | 5 / 10 分钟；简短语音引导想象安静林间，语音之间留出安静时间，可选背景配乐 |

自然声景包含：近岸轻水波、无雷声的细雨、轻微乡野风、岩岸湖水、小溪缓流、平静海岸、傍晚小火。画面包括自然与城市 / 室内方向，例如青苔雨庭 / 云端雨夜、浅湾晨光 / 运河晚居。原图 1672 × 941，当前没有场景视频；图片和录音不是同一地点的同期采集。

## 找回专注

| 功能 | 实际行为 |
| --- | --- |
| 视觉聚焦 | 3 / 5 分钟；观察柔光对象，间隔人声提醒觉察和返回。不能自动检测走神 |
| 声音聚焦 | 3 / 5 分钟；留意间隔出现的柔和音色，无需点击或数拍 |
| 舒尔特表 | 5 / 10 局；按数字顺序点击，可手动选择 3×3、4×4、5×5 难度 |
| 视觉搜索 | 10 / 20 / 30 局；找出颜色与形状均匹配的唯一目标，可选择三档搜索密度 |

点击练习按实际完成局记录用时与误点；不会把未完成部分计为完成。练习中的表现不能直接推断为整体注意力或阅读能力的改善。

## 眼睛休息

眼保健操使用六节原创动画示意定位按摩位置。每节先听手法说明，倒数两秒后进入四个八拍；关闭人声时可看文字。组合休息依次包含眨眼、轻缓方向性眼动、闭眼，时长 3 / 5 分钟。

眼部示意尚未经过专业人员逐图审校，不是医学诊断或治疗建议。先清洁双手、不压眼球；眼睛红肿或皮肤破损时跳过按摩。保持舒服，不快速绕眼、不强迫极限眼动。

## 每次使用的共同操作

1. 在 Mac 菜单栏点击水波图标，或按 `⌘⇧K` 呼出。
2. 选择方法、时长或局数；需要时调整声音、配乐与画面。
3. 点击开始进入沉浸；点击画面可唤出暂停、音量、结束和显示方式控制。自然声景还可“换个画面”。
4. 收起应用时暂停，再次打开后可手动继续。空格暂停 / 继续，Esc 可切到浮窗。

极简、雾光玻璃、暮色玻璃共享布局。可调整面板透明度和呼吸动效色调。Mac 版提供菜单栏、全局快捷键和可拖动桌面浮窗；浏览器版只展示网页层交互。

## 声音和数据

48 段普通话固定引导使用 Marin 预设 AI 音色，保持生成文件原速；环境声七条，背景配乐四首。所有文件随 Mac 应用本地打包，练习时不调用云端生成服务，不需要 API Key。在线浏览器预览首次使用会从网站下载页面与素材。

偏好保存在当前本机 WebView / 浏览器。练习明细只有在用户选择后才保存，最多一百次；没有账号、云同步或遥测上传。详情见 [PRIVACY.md](../PRIVACY.md)。
